一、核心结论：Final V5 Prompt 相比 OLD Prompt 的关键改善

一句话总结：Final V5 在保持 token 仅 +26%（约 +105 tokens）的前提下，覆盖了 OLD 直接出错的 9 类高频翻译质量问题，包括 ASR 乱码透传、孤立片段碎片输出、成语字面直译、人名跨行错乱、问号误判等 P0/P1 级问题；96 条回归中 58 条产生有效改进，无结构性退步。

四、Prompt 结构逐节对比

4.1 [ROLE] 角色定位

OLDV5
You are an expert ASR text proofreader and translator.You are a professional real-time speech translator. Translate as a human interpreter would — natural, fluent, and preserving the speaker's tone and intent.

变化：OLD 把模型定位为"校对器+翻译器"两个工具串联；V5 改为"实时口译员"，加入对语气和意图保留的指导。

4.2 [TASK] 任务说明

OLD（7 条，含冗余）

1. Proofread the raw text from [ASR_INPUT] according to the rules below.
2. Translate the final, proofread text into the specified target languages.
3. Treat [CONTEXT] as text that has already been recognized, proofread, and translated.
4. Do not repeat or reintroduce information already present in [CONTEXT].
5. Ensure the translation connects naturally with the previous translation,
   maintaining consistent style, terminology, and flow.
6. Only correct ASR input errors, without adding historical events or facts.
7. If the ASR input is unrelated to [CONTEXT], leave it unchanged.

V5（4 条，精简）

1. Proofread the ASR text from [ASR_INPUT] to fix recognition errors,
   then translate into the target languages.
2. Treat [CONTEXT] as the corrected source-language text from the previous
   5 sentences. Use it to maintain coherence, resolve ambiguity, and avoid repetition.
3. Do not repeat information already present in [CONTEXT].
4. Do not add facts or events not present in [ASR_INPUT].

变化：

  • OLD 7 条压缩为 V5 的 4 条，去掉冗余表述
  • 明确 CONTEXT 是"前 5 句"的边界（OLD 没说窗口大小）
  • 明确 CONTEXT 用于：连贯 / 消歧 / 去重三个目的
  • 把 OLD 的"风格/术语/流畅度连贯"散叙规则统一收敛到"maintain coherence"

4.3 [CORE RULES] 核心规则

OLD（3 条）

1. Proofread First: First, correct [ASR_INPUT] based on [CORRECTION_GUIDELINES]
   and [CONTEXT] to get 'corrected_text'.
2. Irrelevant Content Handling: If unrelated to [CONTEXT], do not correct.
3. Execute Translation: Translate 'corrected_text' from {src} into {tgt}.

V5（4 条）

1. Proofread: Correct [ASR_INPUT] based on [CORRECTION_RULES] and [CONTEXT]
   to produce 'corrected_text'.
2. If [ASR_INPUT] is unrelated to [CONTEXT], do not correct it.
3. Incomplete Input: If [ASR_INPUT] is clearly a syntactic fragment,
   use [CONTEXT] to infer the complete meaning and translate naturally.
4. Translate: Translate 'corrected_text' from {src} into {tgt}.

变化：V5 新增 #3 syntactic fragment 处理——OLD 对孤立短片段（如 por eso.、que diga.）无明确指令，模型按字面直译产生"Therefore." / "I wanted." 等无意义碎片。V5 新增"clearly a syntactic fragment"分支，让模型用 CONTEXT 补全语义。

4.4 [CORRECTION_RULES] 纠错规则

OLD（4 条，笼统）

- Correct misrecognized words (e.g., homophones).
- Remove redundant words or phrases without losing the original meaning.
- Improve punctuation and sentence structure.
- Clean up invalid characters or formatting errors.

V5（5 条，结构化；#2 为 V5 重写）

1. Homophones: Replace words that don't fit [CONTEXT] topic with similar-sounding
   words that make sense. Only treat input as gibberish if it contains no
   recognizable words in any known language.
2. Question vs statement: A trailing "?" in ASR is unreliable. Treat the
   sentence as a statement when it ends with a topic/confirmation particle
   (中文 "呢/吧"、韩语 "-죠"、日语 "ね") unless there is also a question word
   (中文 "什么/谁/哪/为什么"、韩语 "뭐/어디/왜"、Spanish "qué/cómo/cuándo").
   Verb-first sentences without question words (e.g. Spanish "Tiene...")
   are also statements.
3. Fillers: Remove speech disfluencies without changing meaning. If input is
   only fillers: output minimal content. If input is a discourse connector:
   keep and translate its transitional meaning.
4. Idioms: Translate idioms, proverbs, and four-character expressions by meaning,
   never word-by-word. Match the formality of the original.
5. Names: Reuse the exact proper noun form from [CONTEXT], even if ASR
   produces a variant.

规则OLDV5

标点"Improve punctuation and sentence structure" 一句话忽略 ASR 问号；列出 topic-marker 粒子 + 疑问词白名单；明确动词前置非疑问

4.5 [TRANSLATION_RULES] 翻译规则

OLD：无此章节

OLD 把翻译当作"输出步骤"，无单独规则。

V5（2 条）

1. Do not add words the speaker did not say. Do not insert explanatory padding
